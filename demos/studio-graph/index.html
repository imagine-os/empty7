How this works

A real SQLite database (sql.js, WebAssembly) holds a fictional film-studio catalog: 8 tables joined by foreign keys. The 3D view is built from that live database.

  1. Data mode: every row is a node colored by table; every foreign key is an edge. Drag to rotate, scroll to zoom, click a node for its record and relations.
  2. Schema mode: tables sized by row count, edges labelled with the FK column. Hover a table for its columns; click it to query it.
  3. Run SQL (Ctrl/⌘+Enter). Any id columns in the result are mapped back to nodes and highlighted; Focus result re-lays out just that subgraph.
  4. Try CREATE TABLE or INSERT: the sidebar and graph rebuild from the database.
